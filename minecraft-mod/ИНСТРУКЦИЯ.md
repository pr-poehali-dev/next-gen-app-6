# Мод Create Crafts & Calls — телефонная система для Minecraft

## Что в этой папке

```
minecraft-mod/
├── CreateCraftsAndCalls/            ← исходный код мода (Java-проект на Gradle)
│   ├── build.gradle                 ← настройки сборки, версии зависимостей
│   ├── gradle.properties            ← ID мода, версия, версии Create/NeoForge/SVC
│   └── src/main/java/...            ← весь код мода
│   └── src/main/resources/
│       ├── assets/                  ← текстуры, модели, переводы
│       └── data/                    ← лут-таблицы
├── собранный-мод/
│   └── CreateCraftsAndCalls-1.0.0.jar   ← ГОТОВЫЙ файл, можно сразу ставить на сервер
└── ИНСТРУКЦИЯ.md                    ← этот файл
```

Мод собран и проверен — компилируется без ошибок под **NeoForge 1.21.1**,
использует **Create 6.0.11+** и опционально **Simple Voice Chat**.

---

## Что уже реализовано

- **Телефонный аппарат** — ПКМ поднимает трубку, Shift+ПКМ кладёт. Первый
  игрок, взявший трубку, "привязывается" к телефону.
- **Телефонная станция** — растёт вширь как сундук Create (вверх/вниз/в
  стороны), у каждого блока 4 гнезда.
- **Подключение проводом** — оба блока (телефон и станция) поддерживают
  медную катушку провода из **Create: Crafts & Additions** — тянешь провод
  точно как между обычными разъёмами C&A.
- **Коммутация гаечным ключом** — Shift+ПКМ ключом Create по гнезду выбирает
  вход, следующий клик по другому гнезду — соединяет маршрут. Повторный клик
  по занятому входу — разрывает.
- **Метки над гнёздами** — плашка с именем игрока, подключённого к порту;
  зелёным подсвечивается, если маршрут активен.
- **Энергопотребление** — 5000 FE за каждый блок станции ежесекундно + 1000 FE
  за каждое активное соединение. Кончилась энергия — все звонки обрываются.
- **Голос через Simple Voice Chat** — при замкнутом маршруте и поднятых
  трубках с обеих сторон создаётся временный закрытый голосовой канал. Мод
  собирается и работает и без SVC — тогда просто не будет передачи голоса.

## Вариант 1. Просто установить готовый мод (без программирования)

1. Скачай код проекта: **Скачать → Скачать код**.
2. В архиве найди файл `minecraft-mod/собранный-мод/CreateCraftsAndCalls-1.0.0.jar`.
3. На сервере (NeoForge 1.21.1) в папке `mods` должны также лежать:
   - **NeoForge** сам загрузчик (устанавливается при создании сервера)
   - **Create** (версия 6.0.11 или новее под 1.21.1)
   - **Create: Crafts & Additions** (версия под neoforge-1.21.1)
   - **Simple Voice Chat** — опционально, но без него звонки будут "немыми"
4. Положи `CreateCraftsAndCalls-1.0.0.jar` в ту же папку `mods`.
5. Перезапусти сервер.

То же самое нужно поставить и на клиенты игроков (кроме серверных модов
уровня "server only" — но у нас таких нет, ставь везде одинаково).

## Как это выглядит для игрока

1. Ставишь **Телефон** и рядом (в пределах длины провода) **Станцию**.
2. Берёшь **медную катушку провода** (предмет из Create: Crafts & Additions,
   обычно называется Wire Spool / Copper Wire), кликаешь по гнезду станции,
   потом по телефону — провод протянут.
3. Игрок поднимает трубку (ПКМ по телефону) — видит статус "ожидайте
   телефонистку".
4. "Телефонистка" (любой игрок с гаечным ключом Create) зажимает **Shift** и
   ПКМ кликает по гнезду-входу (загорается), затем по гнезду-выходу — звонок
   соединён, оба игрока слышат друг друга через Simple Voice Chat.
5. Чтобы прервать звонок — Shift+ПКМ ключом ещё раз по тому же входу.

## Про 3D-модели — как добавить, когда их пришлют

Сейчас у обоих блоков — **простые кубы с плоской текстурой**-заглушкой
(сгенерированы автоматически, чтобы мод был визуально узнаваем уже сейчас).
Как только у тебя будут готовые 3D-модели (телефон, трубка отдельно, корпус
станции, блок станции) — вот что нужно сделать:

### Формат моделей
Minecraft-моды используют собственный JSON-формат моделей (`.json` с
описанием кубов-"элементов"), а не `.obj`/`.fbx`/`.gltf` напрямую. 3D-модель
обычно делают в специальной программе **Blockbench** (besplатная, специально
для Minecraft) — https://www.blockbench.net/

1. Открой Blockbench → **Create New → Modded Entity** (или **Generic Model**
   для блока).
2. Собери модель из кубов/текстур либо импортируй готовую (Blockbench умеет
   импортировать .obj и другие форматы для трассировки/референса).
3. **File → Export → Export Java Block/Item Model** — экспортирует именно
   тот `.json`, который нужен Minecraft.

### Куда положить готовые файлы
- Модель блока: `minecraft-mod/CreateCraftsAndCalls/src/main/resources/assets/createcraftsandcalls/models/block/phone.json` (заменить содержимое)
- Модель "трубка снята": `.../models/block/phone_handset_lifted.json`
- Модель станции: `.../models/block/station.json`
- Текстуры (PNG): `.../textures/block/имя_текстуры.png` — путь пропиши внутри
  json-модели в поле `textures`.
- Если нужна отдельная модель **предмета** "трубка в руке" — создай новый
  предмет по образцу существующих в `registry/ModItems.java` (я оставила
  комментарии в коде, откуда копировать паттерн) и модель в
  `models/item/handset.json`.

### Пересборка после замены моделей
Файлы моделей не требуют перекомпиляции Java — их подхватит сама сборка.
Просто нужно заново собрать `.jar` (см. ниже).

## Как самому изменить код или пересобрать jar

### Шаг 1. Установить программы
1. **JDK 21** (обязательно версия 21, не 17!) —
   https://adoptium.net/ru/temurin/releases/?version=21
2. **IntelliJ IDEA Community Edition** (бесплатная) —
   https://www.jetbrains.com/idea/download/

### Шаг 2. Открыть проект
1. Скачай код проекта (**Скачать → Скачать код**).
2. Открой IntelliJ IDEA → **Open** → выбери папку
   `minecraft-mod/CreateCraftsAndCalls` (там, где лежит `build.gradle`).
3. IDEA распознает Gradle-проект и предложит **Load Gradle Project** —
   согласись. Первая загрузка займёт время — Gradle скачивает NeoForge,
   Create и другие зависимости (несколько сотен мегабайт).

### Шаг 3. Редактировать
Весь код лежит в `src/main/java/net/oasis/createcraftsandcalls/`:
- `block/PhoneBlock.java`, `blockentity/PhoneBlockEntity.java` — телефон
- `station/` — вся логика станции: блок, блок-сущность, маршрутизация,
  мультиблочная группировка
- `voicechat/` — интеграция с Simple Voice Chat
- `client/` — рендер проводов и меток над гнёздами
- `registry/` — регистрация блоков/предметов/вкладки творческого режима

### Шаг 4. Собрать jar
В IntelliJ IDEA справа откроется панель **Gradle** (если не видно — **View →
Tool Windows → Gradle**). Разверни:
`CreateCraftsAndCalls → Tasks → build → build` → двойной клик.
Дождись `BUILD SUCCESSFUL`. Готовый файл появится в
`CreateCraftsAndCalls/build/libs/createcraftsandcalls-1.0.0.jar`.

### Шаг 5. Установить на сервер
Так же, как в Варианте 1 — положи `.jar` в папку `mods` сервера и клиентов,
перезапусти.

## Куда именно "загружать код" — важное пояснение

Мод для Minecraft **не публикуется через poehali.dev** — сайт собирает
веб-сайты (React/Python), а Minecraft-моды — это отдельные Java-программы.
Устанавливаются они так:

1. **На свой сервер и клиенты** — кладёшь `.jar` в папку `mods`. Никуда
   отдельно "загружать"/"публиковать" не нужно — мод уже готов к работе.
2. Если захочешь **поделиться модом публично** — это делается на площадках
   вроде **Modrinth** (modrinth.com) или **CurseForge** — там создаётся
   страница проекта и загружается тот же `.jar`. Для твоего собственного
   сервера это НЕ требуется.

## Частые проблемы

**"Missing or unsupported mandatory dependencies" при запуске сервера**
В логе будет указано, какого мода не хватает — обычно это Create, Create:
Crafts & Additions или несовпадение версии NeoForge. Установи указанную
версию.

**Провод не подключается к телефону/станции**
Провод из Create: Crafts & Additions (не наш собственный предмет) — оба
блока (телефон и станция) уже поддерживают подключение "из коробки". Убедись,
что кликаешь именно катушкой провода (Wire Spool), а не другим предметом.

**Гаечный ключ не переключает маршруты**
Работает именно **гаечный ключ из мода Create** (не любой другой) с зажатым
**Shift**. Обычный клик (без Shift) по станции просто показывает количество
активных соединений.

**Игроки не слышат друг друга**
Проверь: 1) установлен ли Simple Voice Chat на сервере и у обоих клиентов,
2) подняты ли трубки на ОБОИХ телефонах, 3) есть ли активный маршрут между
их портами (проверь метку над гнездом — должна стать зелёной), 4) хватает ли
энергии станции (FE) — при недостатке энергии маршруты сбрасываются
автоматически.
