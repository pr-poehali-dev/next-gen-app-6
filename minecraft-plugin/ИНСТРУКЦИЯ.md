# Плагин AuctionShop — аукцион и магазин для сервера Minecraft (Paper 1.19.3)

## Что в этой папке

```
minecraft-plugin/
├── AuctionShop/                     ← исходный код плагина (Java-проект)
│   ├── pom.xml                      ← файл настроек сборки (Maven)
│   └── src/main/java/...            ← весь код плагина
│   └── src/main/resources/
│       ├── plugin.yml               ← команды и права плагина
│       └── config.yml               ← настройки (мин/макс цена лота)
├── собранный-плагин/
│   └── AuctionShop-1.0.0.jar        ← ГОТОВЫЙ файл, можно сразу закинуть на сервер
└── ИНСТРУКЦИЯ.md                    ← этот файл
```

---

## Вариант 1. Просто установить готовый плагин (без программирования)

Если тебе не нужно менять код — просто используй готовый файл.

1. Скачай код проекта: **Скачать → Скачать код** (в интерфейсе poehali.dev).
2. В скачанном архиве найди файл:
   `minecraft-plugin/собранный-плагин/AuctionShop-1.0.0.jar`
3. Загрузи этот файл на сервер в папку `plugins` (там же, где лежит Paper.jar
   и другие плагины).
4. Перезапусти сервер.
5. Готово — команды `/ah`, `/auc`, `/auction` (аукцион) и `/shop` (магазин)
   уже работают.

Плагин сам создаст себе служебные файлы в папке `plugins/AuctionShop/`:
- `balances.yml` — баланс монет игроков
- `auction.yml` — активные лоты аукциона
- `shop.yml` — товары постоянного магазина (при первом запуске сам
  заполнится базовым набором — камень, дерево, железо, алмазы и т.д.)
- `config.yml` — настройки мин/макс цены лота

## Команды плагина

### Аукцион
| Команда | Что делает |
|---|---|
| `/ah` или `/auc` или `/auction` | Открыть окно аукциона со всеми лотами |
| `/ah sell <цена>` | Выставить предмет из руки на продажу за указанную цену |
| `/ah mail` | Открыть «Посылки» — предметы/деньги, которые не влезли в инвентарь |
| `/ah my` | Показать свои активные лоты (можно снять с продажи кликом) |

В окне аукциона:
- клик по товару — купить
- кнопка «Категория» — переключить фильтр (оружие, броня, еда и т.д.)
- кнопка «Сортировка» — переключить (цена ↑ / цена ↓ / сначала новые)
- стрелки внизу — листать страницы

### Магазин сервера
| Команда | Что делает |
|---|---|
| `/shop` | Открыть окно магазина |
| `/shop additem <цена_покупки> <цена_продажи>` | (только для админов) Добавить предмет из руки в магазин |
| `/shop removeitem <id>` | (только для админов) Убрать товар из магазина |

В окне магазина:
- ЛКМ по товару — купить 1 шт
- ПКМ — купить сразу 64 шт
- Shift + ЛКМ — продать 1 шт из своего инвентаря
- Shift + ПКМ — продать весь стек

### Баланс монет
| Команда | Что делает |
|---|---|
| `/balance` | Посмотреть свой баланс |
| `/balance <ник>` | Посмотреть баланс другого игрока |
| `/balance give <ник> <сумма>` | (только для админов) Выдать монеты игроку |

**Важно:** у плагина своя встроенная экономика (не Vault). Чтобы выдать
игрокам монеты для старта — используй `/balance give`.

### Права доступа
- `auctionshop.use` — доступ к `/ah` и `/shop` (по умолчанию есть у всех игроков)
- `auctionshop.admin` — доступ к `/shop additem`, `/shop removeitem`,
  `/balance give` (по умолчанию есть только у операторов сервера, `/op`)

## Вариант 2. Изменить код плагина самому

Если захочешь что-то доработать (например, изменить стартовые товары
магазина, добавить новую категорию предметов) — нужно:

### Шаг 1. Скачать код
**Скачать → Скачать код** — в архиве будет вся папка `minecraft-plugin`.

### Шаг 2. Установить программы для разработки
1. **JDK 17** (Java Development Kit) — https://adoptium.net/ru/temurin/releases/
   Скачай установщик для своей ОС, версия **17**.
2. **IntelliJ IDEA Community Edition** (бесплатная) —
   https://www.jetbrains.com/idea/download/
   Это среда разработки ("студия"), где удобно редактировать Java-код.

### Шаг 3. Открыть проект в IntelliJ IDEA
1. Открой IntelliJ IDEA → **Open** → выбери папку `minecraft-plugin/AuctionShop`
   (именно ту, где лежит файл `pom.xml`).
2. IDEA сама распознает, что это Maven-проект, и предложит скачать
   зависимости (в том числе Paper API) — нажми **Load Maven Project** /
   **Import Changes**, если появится всплывающее окно. Это может занять
   пару минут при первом открытии — качается библиотека Paper с интернета.

### Шаг 4. Редактировать код
Весь код лежит в `src/main/java/me/oasis/auctionshop/`:
- `AuctionShopPlugin.java` — главный файл, точка входа
- `auction/` — логика аукциона
- `shop/` — логика магазина
- `economy/` — баланс монет
- `gui/` — окна (инвентари) и обработка кликов
- `commands/` — команды `/ah`, `/shop`, `/balance`
- `util/` — категории предметов, сортировка

Например, чтобы добавить новый стартовый товар в магазин — открой
`shop/ShopManager.java`, найди метод `seedDefaultItems()` и добавь строку
по образцу:
```java
addItem(new ItemStack(Material.NETHERITE_INGOT), 5000, 2500);
```
(Материал — это блок/предмет из майнкрафта; первая цена — за сколько
можно купить 1 шт, вторая — за сколько магазин выкупит её у игрока.)

### Шаг 5. Собрать готовый .jar-файл
В IntelliJ IDEA справа есть панель **Maven** (если не видно — открой её через
меню **View → Tool Windows → Maven**). Там:
1. Разверни `AuctionShop → Lifecycle`
2. Дважды кликни на **package**
3. Подожди сборку (внизу появится `BUILD SUCCESS`)
4. Готовый файл появится в папке `AuctionShop/target/AuctionShop-1.0.0.jar`

### Шаг 6. Загрузить на сервер
Точно так же, как в Варианте 1 — закинь получившийся `.jar` в папку
`plugins` на сервере и перезапусти его.

## Куда именно "загружать код" — важное пояснение

Мод (плагин) для Minecraft **не публикуется через poehali.dev** — сайт
собирает только веб-сайты (React/Python), а плагины для Minecraft — это
отдельные Java-программы. Их устанавливают:

1. **Локально на свой сервер** — просто кладёшь `.jar` файл в папку
   `plugins` рядом с `paper.jar` (или spigot.jar), и сервер сам его
   подхватывает при следующем запуске. Никуда "публиковать" код отдельно
   не нужно.
2. Если хочешь **поделиться плагином с другими** (выложить в открытый
   доступ) — это делается на специализированных площадках для Minecraft
   плагинов, например SpigotMC (spigotmc.org) или Modrinth (modrinth.com).
   Но для твоего собственного сервера это не требуется — плагин уже готов
   к использованию прямо сейчас.

## Частые проблемы

**Сервер не включается / плагин не появляется в списке**
Убедись, что версия сервера — **Paper 1.19.3** (плагин собран именно под
неё). Проверить версию: команда `/version` в консоли сервера.

**Ошибка "Unsupported API version" в логах**
Значит версия сервера отличается от 1.19.3. Напиши мне версию твоего
сервера — пересоберу плагин под неё.

**В магазине не хватает нужных товаров**
Используй `/shop additem <цена_покупки> <цена_продажи>`, держа нужный
предмет в руке — так можно добавить любой блок/предмет игры вручную,
без редактирования кода.
